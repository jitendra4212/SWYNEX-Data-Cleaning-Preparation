
# SWYNEX - Data Cleaning & Preparation

## Project Overview
This project focuses on cleaning and preparing
the Titanic Passenger Dataset for data analysis.

## Internship Task
Task 1 - SWYNEX Technologies

## Technologies Used
- Python
- Pandas
- NumPy

## Dataset
Titanic Passenger Dataset (Public Dataset)

## Data Cleaning Operations
1. Identified missing values.
2. Handled missing Age values using median.
3. Handled missing Embarked values using mode.
4. Replaced missing Cabin values with Unknown.
5. Checked and removed duplicate records.
6. Standardized categorical text values.
7. Corrected numerical data types.
8. Exported the cleaned dataset.

## Project Structure
- data/raw: Original dataset
- data/cleaned: Cleaned dataset
- clean_data.py: Data cleaning script
- validation_report.py: Validation script
- requirements.txt: Required libraries

## How to Run

Install dependencies:

pip install -r requirements.txt

Run cleaning script:

python clean_data.py

Run validation:

python validation_report.py

## Output
The cleaned dataset and validation reports
are saved in the data folder.
